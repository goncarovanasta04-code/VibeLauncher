1. О ПРОЕКТЕ И АРХИТЕКТУРЕ
================================================================================
VibeLauncher — современный, стильный и производительный кастомный лаунчер Minecraft.
Поддерживает аккаунты Ely.by (с бесплатными скинами и плащами), Microsoft/Xbox и Офлайн-режим.
Главная цель: красивый интерфейс (Liquid Glass 2.0, 3D скины, живые фоны), но при этом
абсолютная стабильность запуска любых версий игры даже на самых слабых компьютерах.

Структура проекта:
├── electron/
│   ├── main.js         — Главный процесс Electron, IPC обработчики, запуск игры
│   ├── java.js         — Детектор, скачивание и кэширование Java (8, 17, 21 x64 Temurin)
│   ├── potato.js       — Режим «Potato PC»: патчинг options.txt и настройки JVM
│   ├── updater.js      — Проверка и загрузка обновлений лаунчера с GitHub Releases
│   ├── discord.js      — Discord Rich Presence интеграция
│   └── preload.js      — Безопасный мост contextBridge между Electron и React
├── src/
│   ├── pages/
│   │   ├── Home.jsx       — Главный экран: кнопка Запустить/Установить, выбор версии, статус
│   │   ├── Settings.jsx   — Настройки лаунчера, памяти, Java, выбор режима Potato PC
│   │   ├── Mods.jsx       — Каталог модов, ресурспаков и шейдеров Modrinth
│   │   └── Skins.jsx      — Гардероб скинов и плащей (3D skinview3d)
│   └── components/
│       ├── ChangelogModal.jsx — Окно со списком изменений всех версий
│       ├── CrashModal.jsx     — Окно диагностики и разбора ошибок при краше игры
│       ├── SettingsModal.jsx  — Всплывающее окно настроек
│       └── ...
├── scripts/
│   ├── publish-release.js — Скрипт сборки и публикации релизов на GitHub
│   └── afterPack.js       — Прошивка иконки в .exe через rcedit
├── package.json        — Зависимости и метаданные проекта
├── publish_update.bat  — Батник для сборки и выкладки обновления в 1 клик
└── .env                — Локальный файл с переменными окружения (GITHUB_TOKEN)

2. ЧТО УЖЕ СДЕЛАНО (ВЫПОЛНЕННЫЕ ЗАДАЧИ)
================================================================================

[+] 1. Автоматическая установка и кэширование Java:
    - Интеллектуальный анализ версии Minecraft:
        * Minecraft <= 1.16.5  -> Java 8
        * Minecraft 1.17 - 1.20.4 -> Java 17
        * Minecraft 1.20.5+ и новые сборки Fabric/NeoForge -> Java 21
    - Автоматическое скачивание официального 64-битного OpenJDK Temurin (Adoptium)
      в локальную папку `runtimes/java-X`.
    - Кэширование: если нужная Java уже установлена/скачана, повторное скачивание
      НЕ запускается! Лаунчер использует готовый бинарник.
    - Исправлен фатальный сбой «Could not create the Java Virtual Machine»:
        * Исключена 32-битная Java, на которой игра вылетала из-за лимита адресации памяти.
        * Убраны несовместимые флаги (-XX:+AlwaysPreTouch) на слабых машинах.
        * Автоматически гарантируется Xms <= Xmx.

[+] 2. Поддержка любых версий и кастомных сборок:
    - Глубокий парсинг JSON-манифестов (`inheritsFrom`, `jar`, `assets`, `javaVersion`).
      Лаунчер корректно понимает родительскую версию майна для любых кастомных
      сборок, OptiFine, Fabric, Forge и самодельных папок игроков.
    - Автономный резолвер локальных папок в `%APPDATA%/.minecraft/versions/`.

[+] 3. Улучшения интерфейса и UX запуска:
    - Динамическая кнопка «Установить» / «Запустить»: если версия еще не скачана на ПК,
      кнопка подсвечивается зеленым и пишет «Установить». После загрузки — «Запустить».
    - Кнопка «Обновить каталог версий» (🔄): позволяет в 1 клик перезагрузить список
      версий, если пользователь вручную закинул сборку в папку versions.
    - Плавный монотонный индикатор установки: исключены скачки шкалы прогресса назад,
      выводятся понятные шаги (подготовка Java, загрузка ассетов, проверка библиотек).
    - Окно диагностики крашей (Crash Dialog): при ошибке игры парсит логи и выводит
      человеческое объяснение (видеодрайвер OpenGL, нехватка RAM, конфликт модов, битый файл).
    - Разгрузка системы: при старте окна игры лаунчер полностью сворачивается/скрывается,
      снижая потребление GPU и ОЗУ до 0%. При закрытии игры лаунчер моментально возвращается.

[+] 4. Режим «Potato PC» (Для очень слабых ПК):
    - В настройках добавлена отдельная опция/карточка «Potato PC».
    - В самом лаунчере: отключает тяжелый видео-фон, 3D Canvas анимации и лишние эффекты.
    - В игре Minecraft: автоматически патчит `options.txt` в корне и внутри изолированных
      папок версий:
        * renderDistance = 4 чанка
        * simulationDistance = 4
        * particles = minimal
        * clouds = off
        * smooth lighting (ao) = off
        * entityShadows = false
        * mipmapLevels = 0
        * framerateLimit = 60
        * viewBobbing = false
    - В параметрах JVM: выставляет легкие флаги сборщика мусора и безопасный лимит памяти,
      предотвращая зависание системы с 2-4 ГБ ОЗУ.

[+] 5. Безопасность и релизный пайплайн:
    - Полная зачистка приватных токенов из исходного кода.
    - Токен GitHub теперь считывается строго из переменной окружения или локального `.env`.
    - Успешно собрана и опубликована версия v1.3.9 на GitHub Releases:
      https://github.com/goncarovanasta04-code/VibeLauncher/releases/tag/v1.3.9
    - Удобный скрипт `publish_update.bat` для быстрого релиза следующих версий.

4. КАК ЗАПУСКАТЬ, ТЕСТИРОВАТЬ И СОБИРАТЬ
================================================================================

1. Запуск в режиме разработки:
   $ npm run dev
   (Одновременно стартует Vite dev-сервер на порту 5173 и Electron)

2. Проверка сборки без создания инсталлятора:
   $ npm run build

3. Сборка готового инсталлятора (.exe):
   $ npm run dist
   (Файл установщика появится в папке release/VibeLauncher-Setup-v1.3.9.exe)

4. Публикация нового релиза на GitHub:
   - Запустить `publish_update.bat`
   - Или выполнить команду:
     $ npm run release [номер_версии]
     (Убедитесь, что в файле .env или окружении задан GITHUB_TOKEN=ваш_токен)
